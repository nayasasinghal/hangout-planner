# 🌍 Outsy – Hangout Finder

**Find your vibe. Plan your hangout. Make memories.**

Outsy is a frontend web development project that helps users explore hangout spots and organize outings with friends through a modern, user-friendly interface.

## ✨ Features

- 🏠 **Home Page** – Introduction to Outsy and its features.
- 🔎 **Explore Places** – Browse different hangout categories and destinations.
- ❤️ **Favourites** – View favourite hangout spots.
- 📅 **Create Plans** – Interface for planning outings with friends.
- 🔐 **Login & Registration** – User interface for login and account registration.
- 🎨 **Modern UI** – Stylish design, navigation, hover effects, and responsive layouts.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension, if needed.
4. Right-click `vibefind.html`.
5. Select **Open with Live Server**.

You can now explore the Outsy website in your browser.
